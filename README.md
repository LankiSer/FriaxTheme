# Custom WooCommerce Theme

Современная тема для интернет-магазина с поддержкой WooCommerce и ACF блоков.

## Описание

Эта тема создана специально для интернет-магазинов с использованием WooCommerce и Advanced Custom Fields (ACF). Включает в себя готовые блоки для создания красивых и функциональных страниц магазина.

## Особенности

- **WooCommerce интеграция** - полная поддержка WooCommerce
- **ACF блоки** - готовые блоки для создания контента
- **Мобильная адаптация** - отзывчивый дизайн
- **SEO оптимизация** - семантическая разметка
- **Производительность** - оптимизированный код
- **Кастомизация** - легко настраиваемые стили

## Быстрый старт

### 1. Установка темы

1. Скопируйте папку темы в `wp-content/themes/`
2. Активируйте тему в админке WordPress
3. Установите необходимые плагины

### 2. Необходимые плагины

- **WooCommerce** - для работы интернет-магазина
- **Advanced Custom Fields Pro** - для создания блоков
- **Contact Form 7** - для форм обратной связи

### 3. Настройка ACF блоков

1. Перейдите в админку WordPress → Custom Fields → Field Groups
2. Создайте новую группу полей
3. Добавьте поля для ваших блоков
4. Настройте правила отображения

## Структура темы

```
theme/
├── assets/                 # Статические файлы
│   ├── css/               # Стили
│   ├── js/                # JavaScript
│   └── images/            # Изображения
├── inc/                   # Вспомогательные файлы
│   ├── blocks/            # ACF блоки
│   ├── template-functions.php
│   └── woocommerce-support.php
├── woocommerce/           # Шаблоны WooCommerce
├── functions.php          # Основные функции
├── style.css              # Основные стили
└── index.php              # Главный шаблон
```

## ACF блоки

### Доступные блоки

- **Hero Banner** - главный баннер с кнопкой
- **Product Grid** - сетка товаров
- **Features List** - список преимуществ
- **Testimonials** - отзывы клиентов
- **Contact Form** - форма обратной связи

### Создание нового блока

1. Создайте папку в `inc/blocks/your-block/`
2. Добавьте файлы:
   - `index.php` - регистрация блока
   - `render.php` - шаблон отображения
   - `style.css` - стили блока
   - `script.js` - JavaScript (опционально)

## WooCommerce

### Настройка магазина

1. Перейдите в WooCommerce → Настройки
2. Настройте валюту и регион
3. Добавьте товары
4. Настройте способы оплаты и доставки

### Кастомизация шаблонов

Все шаблоны WooCommerce находятся в папке `woocommerce/`. Вы можете их редактировать под свои нужды.

## Кастомизация

### Цвета и шрифты

Основные стили находятся в `assets/css/main.css`. Вы можете изменить:

- Цветовую схему
- Шрифты
- Размеры элементов
- Отступы и поля

### JavaScript

Основной JavaScript находится в `assets/js/main.js`. Модули:

- `mobile-menu.js` - мобильное меню
- `modal-manager.js` - управление модальными окнами
- `woocommerce-ajax.js` - AJAX для WooCommerce

## Мобильная адаптация

Тема полностью адаптирована для мобильных устройств:

- Адаптивная сетка
- Мобильное меню
- Оптимизированные изображения
- Touch-события

## Разработка

### Требования

- PHP 8.0+
- WordPress 6.4+
- WooCommerce 8.0+
- ACF Pro 6.0+

### Локальная разработка

1. Установите локальный сервер (XAMPP, MAMP, etc.)
2. Создайте базу данных WordPress
3. Установите WordPress
4. Активируйте тему и плагины
