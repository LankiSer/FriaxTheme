# Настройки темы WordPress

## Описание
Создана система управления настройками темы через админку WordPress для редактирования данных хедера и футера.

## Что добавлено

### 1. Файл настроек
- `inc/theme-settings.php` - основной файл с настройками
- Подключен в `functions.php`

### 2. Страница в админке
- **Путь**: Внешний вид → Настройки темы
- **URL**: `/wp-admin/themes.php?page=theme-settings`

### 3. Настраиваемые поля

#### Логотип и компания
- **Логотип** - загрузка изображения через медиабиблиотеку
- **Название компании** - основное название (например: FRIA)
- **Подзаголовок компании** - подзаголовок (например: INDUSTRIE, HOLDING)

#### Контактная информация
- **Телефон** - для ссылок (например: 7(499)677-24-40)
- **Отображение телефона** - как отображается на сайте
- **Адрес** - полный адрес компании
- **Часы работы (кратко)** - краткий формат (ПН-ПТ С 10.00 ДО 18.30)
- **Часы работы (подробно)** - подробный формат (По будням: с 10:00 до 18:00)

#### Копирайт
- **Копирайт** - название компании для копирайта
- **Год копирайта** - год для копирайта

### 4. Обновленные шаблоны

#### header.php
- Использует новые функции для получения настроек
- Добавлена контактная информация в хедер
- Обновлено мобильное меню

#### footer.php
- Использует новые функции для получения настроек
- Обновлен логотип и информация о компании
- Обновлена контактная информация
- Обновлен копирайт

### 5. Дополнительно
- **page-contacts.php** - шаблон страницы контактов
- Использует данные из настроек темы
- Красивый дизайн с иконками

## Функции для разработчиков

```php
// Получение настроек в шаблонах
get_theme_logo()                    // Логотип
get_theme_company_name()           // Название компании
get_theme_company_subtitle()       // Подзаголовок компании
get_theme_phone()                  // Телефон для ссылок
get_theme_phone_display()          // Отображение телефона
get_theme_address()               // Адрес
get_theme_working_hours()         // Часы работы (кратко)
get_theme_working_hours_display() // Часы работы (подробно)
get_theme_copyright()             // Копирайт
get_theme_copyright_year()        // Год копирайта
```

## Как использовать

1. Перейдите в админку WordPress
2. Выберите **Внешний вид → Настройки темы**
3. Заполните все необходимые поля
4. Нажмите **Сохранить изменения**
5. Изменения сразу отобразятся на сайте

## Безопасность
- Все поля проходят санитизацию
- Используется nonce для защиты от CSRF
- Проверка прав доступа

## Совместимость
- WordPress 5.0+
- PHP 7.4+
- Работает с существующими темами
